# Política de correções

## Como pedir
Escreva para o e-mail de correções indicado no rodapé do site, com:

- o link da análise;
- o trecho que está errado;
- a fonte que mostra o erro (link, documento ou dado público).

Também é possível abrir uma *issue* pública neste repositório.

> **Pendente (Everaldo):** prazo de resposta. Sugestão: "todo pedido recebe resposta em até 7 dias".
> PRAZO: _PREENCHER_

## O que acontece
1. O pedido é conferido contra as fontes.
2. Se procede, a análise é corrigida e **a correção é registrada no próprio texto**, na seção
   "Correções e atualizações", com a data e o que mudou. O texto antigo não é apagado em
   silêncio.
3. Se o veredito muda, o registro diz qual era o anterior e qual é o novo, e por quê.
4. Se não procede, quem pediu recebe a explicação.

## Tipos de registro
- **Correção**: havia um erro (número, data, nome, contexto).
- **Atualização**: surgiu um fato novo depois da publicação.
- **Mudança de veredito**: sempre registrada, com o motivo.

Formato usado no site:

```
20/11/2026: incluída a decisão do STF de 19/11 e atualizado o veredito para "enganoso".
```

## O que nunca é feito
- Mudar a data de publicação para parecer que o texto sempre disse a versão nova.
- Apagar uma análise para esconder um erro. Se uma análise precisar sair do ar, a página fica com
  uma nota explicando o motivo.
- Mudar o endereço (slug) de uma análise corrigida.

## Página pública de correções
O site tem uma página que lista todas as análises com correções ou atualizações registradas, das
mais recentes para as mais antigas: noticiasnacionais.com.br/correcoes/.
