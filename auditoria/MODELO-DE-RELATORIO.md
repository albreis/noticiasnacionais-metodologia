## 3. Verificação por análise
Para cada análise sorteada, preencher:

| Critério | Cumpre? (sim / parcial / não) | Observação |
|---|---|---|
| Pelo menos 3 fontes de 2 sites diferentes | | |
| Toda afirmação conferida tem fonte que a sustenta | | |
| Algum link quebrado ou fonte que não diz o que o texto atribui a ela | | |
| Linha do tempo: cada item tem evidência e a relação (direta/indireta/contexto) é razoável | | |
| Veredito coerente com a escala e com as fontes | | |
| Confiança coerente com a qualidade das fontes | | |
| Visões políticas: mesmo cuidado e extensão para cada lado | | |
| Linha editorial das fontes variada quando o tema é político | | |
| Texto sem trechos copiados das fontes | | |
| Mídias com crédito e licença | | |
| Correções registradas quando houve mudança | | |
| Nada sugere que o autor é jornalista ou veículo de imprensa | | |

Veredito do auditor para a análise: concorda / discorda (com o veredito que daria e por quê).

## 4. Análise do conjunto
- Distribuição dos vereditos por lado político das afirmações avaliadas (quando aplicável):
  há diferença de rigor entre lados?
- Distribuição dos temas: algum lado ou grupo aparece muito mais como alvo?
- Pedidos de correção recebidos no período, quantos procederam e em quanto tempo foram atendidos.
- Cumprimento da política de financiamento e conflito de interesse.
