# Política de fontes

## Mínimo obrigatório
- **3 fontes, de pelo menos 2 sites diferentes**, em toda análise. O ideal são 5 ou mais.
- **Toda afirmação** do texto (número, data, citação, fato) precisa estar numa fonte listada ou no
  link de um item da linha do tempo. Sem fonte, não entra.
- Todas as fontes aparecem no fim da análise, com link.

## Ordem de preferência
1. Documentos oficiais e dados públicos: Diário Oficial, IBGE, ANP, Banco Central, tribunais,
   Câmara, Senado, órgãos de governo.
2. Agências de notícias.
3. Veículos de imprensa com **linhas editoriais diferentes**: quando o tema é político, pelo menos
   um de cada lado.
4. Agências de checagem.
5. Estudos acadêmicos e especialistas identificados.
6. Partes interessadas (empresas, partidos, governos falando de si mesmos): valem para registrar
   a posição delas, não como prova independente.

Redes sociais nunca são fonte única de um fato; servem para registrar o que alguém disse.

## Como cada fonte é registrada
Cada fonte da análise tem: título, veículo, link, tipo e, quando aplicável, a linha editorial
percebida e a data.

**Tipos:** documento oficial, dados públicos, imprensa, agência de notícias, agência de checagem,
estudo acadêmico, especialista, parte interessada, outra.

**Linha editorial percebida (opcional):** não se aplica, esquerda, centro-esquerda, centro,
centro-direita, direita.

O site mostra um resumo no topo da lista de fontes (quantas de cada tipo e de cada linha
editorial), para o leitor ver o equilíbrio de cada análise.

## Sobre a classificação de linha editorial
A linha editorial de um veículo é uma **percepção**, não um rótulo oficial, e serve só para o leitor
ver se uma análise ouviu lados diferentes. Ela é registrada em cada fonte, análise por análise. Para
evitar que o mesmo veículo receba classificações diferentes, a
[revisão por amostragem](auditoria/REVISAO-POR-AMOSTRAGEM.md) confere a consistência e, quando um
veículo aparecer com linhas diferentes, a classificação passa a ser fixada numa tabela neste arquivo.

## Cópias arquivadas
A partir da metodologia 1.0, cada fonte pode ter um link para uma **cópia arquivada** (por exemplo,
no [Internet Archive](https://web.archive.org)), feita no momento da consulta. Assim, se a página
original mudar ou sair do ar, dá para conferir o que ela dizia. Veja
[REGISTRO-POR-ANALISE.md](REGISTRO-POR-ANALISE.md).

## Texto original
Nada é copiado. Citação literal só curta (até cerca de 25 palavras), entre aspas e com a fonte. O
resto é síntese própria, cruzando as fontes.
